# Product

This document describes the product intent for AI Study Future Planner. It is context for development. It is not a data store.

## Audience

Students who want a structured way to move from a future goal to daily study.

## Promise

A student defines where they are headed. The product then helps them follow one personalized learning journey:

Goal → AI Future Roadmap → Study Plan → Daily Tasks → AI Quiz → Performance Tracking → Adaptive Study Plan → AI Tutor

Each stage should stay connected to the same goal. Later stages should be able to change the plan when practice shows a gap.

## Experience principles

- Start from a destination, then derive the work.
- Keep roadmap, plan, tasks, practice, and review on one path.
- Feel calm, trustworthy, and precise. The interface should help a student focus.
- Make progress visible enough that the next study session is obvious.

## Public presence

The current public page introduces the product and the learning sequence. It does not create goals, generate plans, or call an AI provider.

## Current phase

Foundation only:

- Next.js application shell
- Visual system and home page
- Documentation
- Environment variable structure

## Not in this phase

Accounts, saved student data, AI generation, quizzes, dashboards, and payments are later phases. Do not treat this document as permission to build them early.
